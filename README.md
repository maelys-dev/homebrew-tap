# Maelys Homebrew tap

Homebrew formulae for Maelys tools. Works on macOS and Linux.

```sh
brew install maelys-dev/tap/mcp-runtime
```

`mcp-runtime` builds from source and installs the `maelys-mcp` host, the static
library `libmaelys_mcp.a`, and the public headers. See the project at
https://github.com/maelys-dev/mcp-runtime
